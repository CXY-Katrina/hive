# 硬件型号、SoC 与算力规格

2026-09-12，已在当前 5 台 A3 节点完成只读查询，共核验 80 个逻辑设备。

## 型号从哪里来

纳管时记录的 `Atlas 800I A3 / IT22HMDA_4_S` 和 `AC222 / IT22HMDA_2_S` 是两个字段的组合，并非 SoC 型号。页面现只显示服务器型号，隐藏板卡后缀和默认集群名；自定义集群名仍可显示。原始字段保留，机型申请同时兼容原完整名称与简化后的服务器型号：

```bash
# 系统产品名：Atlas 800I A3 或 AC222
cat /sys/class/dmi/id/product_name

# 板卡产品名：输出中的 Product Name
npu-smi info -t board -i 0

# 芯片身份：按设备映射查询每个 NPU ID / Chip ID
npu-smi info -t board -i 0 -c 0
```

这批 A3 的第三条命令返回 `Chip Name: Ascend910`、`NPU Name: 9362` 或 `9382`，组合得到 `Ascend910_9362` 或 `Ascend910_9382`。`Chip Version: V1` 是另一个字段，不能用它替代 SoC version。这种组合方式也见于 [vLLM Ascend 的硬件识别实现](https://github.com/vllm-project/vllm-ascend/blob/main/setup.py)。

| 节点 IP 尾号 | 系统产品 / 板卡产品 | 实机 SoC version |
|---|---|---|
| 159、197、198 | Atlas 800I A3 / IT22HMDA_4_S | Ascend910_9362 |
| 169、174 | AC222 / IT22HMDA_2_S | Ascend910_9382 |

## 展示与记录

| 字段 | 来源 / 口径 | 展示与保存 |
|---|---|---|
| 系统产品 | DMI | 节点硬件详情；保留最新值 |
| 板卡产品 | npu-smi board | 保留在后台元数据，不在页面展示 |
| SoC version | 每个逻辑设备的芯片身份 | 集群台账、实时节点头、设备详情；保留逐设备值与节点去重列表 |
| Chip version | npu-smi 的 Chip Version | 硬件详情；逐设备保留最新值 |
| 采集质量、原因、时间、boot_id、查询来源 | 完整性及重启核验 | 硬件详情；保留最新记录 |
| 算力 | A3 的 FP16 稠密理论峰值，TFLOPS / 双芯模块 | 集群台账、实时节点头、详情；由管理员登记，保留数值、资料来源、确认时 SoC 和登记时间 |

算力是硬件规格，不是 AI Core 利用率、实测吞吐量或整机总算力，也不是单个逻辑设备的算力。当前未取得足以确认 `9362/9382` 与 `560/752` 一一对应的规格资料，因此这五台节点的算力显示“待确认”，不根据机型名猜测。管理员可在“集群管理 → 查看检测结果 → 登记算力规格”中填写明确数值与依据，或清除登记。页面要求正数和非空来源，后端重复校验并记录审计。

仅在当前 A3 SoC 采集完整且 boot_id 一致时接受双芯模块算力登记。后续 SoC 不同或采集不完整时，已登记数值显示“待复核”。A2/A5 的 SoC 识别接口已预留；当前没有实机验证，不沿用 A3 的双芯算力口径。

## 模块与依赖

`hardware_profile.py` 独立处理静态身份采集，由 Ascend 适配器通过 `describe_hardware` 暴露。纳管检测、手动重新检测以及重启触发的重新检测使用同一入口，不加入每 15 秒的实时采样。每批查询核验重启前后 boot_id 和返回的设备身份；缺失信息显示待确认，不影响正常实时指标的采集质量。

最新规格保存在 MySQL 已有的 `nodes.metadata.hardware_profile` / `compute_spec`，不新增表、时序指标或聚合统计。资源申请与释放规则保持现有行为；算力目前是展示属性，尚未加入申请筛选条件。

无新增依赖：中心复用现有 Python/SSH/MySQL；节点使用现有 Bash、coreutils（cat、timeout）、驱动提供的 npu-smi 及 DMI sysfs。未安装 CANN、PyTorch 或常驻组件，也未执行算力压测。

## 验证

本次相关 74 项测试通过，覆盖身份解析、逐设备完整性、重启、异常回包、管理员权限、登记输入、规格来源和清除动作；MySQL 集成测试使用独立临时库。前端生产构建通过，浏览器模拟接口验证登记/清除、SoC 变化失效和移动端布局。真实节点只采集规格，不写入未确认的算力。
